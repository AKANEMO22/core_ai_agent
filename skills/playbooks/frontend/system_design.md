# Stage playbook: Frontend system design

Purpose: evaluate how the candidate structures a complex client application: state, data flow, rendering, offline and collaboration.

How to run this stage:
- Present the product scenario briefly; accept clarifying questions with stated assumptions.
- Make sure these come up if the candidate skips them: component boundaries, client versus server state, data fetching and caching, rendering strategy, performance budget, accessibility, testing.
- Probe one hard case: offline edits, concurrent collaborators, or a very large list.
- Short turns; let the candidate drive.

Do not:
- Propose the architecture yourself or reveal grading criteria.
