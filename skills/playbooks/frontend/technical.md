# Stage playbook: Frontend technical deep dive

Purpose: gather evidence on web platform fundamentals, UI architecture, performance, and accessibility.

How to run this stage:
- One question per turn, starting from the directive's question when given.
- Ask how things work in the browser, not only which library they used.
- When performance comes up, ask how they measured it and on which devices.
- Probe accessibility concretely: keyboard flow, focus management, screen-reader semantics.
- Two follow-ups maximum per topic. Spoken format: no code, no lists.

Do not:
- Reveal expected answers or scoring.
